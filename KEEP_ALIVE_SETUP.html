Dashboard Keep-Alive Setup

Keep your Vercel deployment always-on with one of these options

The Problem

Your Vercel dashboard is deployed at:

https://can-logger-dnmjx9hbq-abhishek-e.vercel.app

Vercel's free tier spins down serverless functions after ~15 minutes of inactivity. This means:

  • First visit: 2-5 second cold start
  • Idle 15 min: function goes to sleep
  • Next visit: cold start again

To fix this, pick one of the three options below.

RECOMMENDED Option 1: Free Cron Ping

Use a free cron service to ping your dashboard every 5 minutes. It wakes up instantly on each ping.

  1. Go to cron-job.org
  2. Sign up (free tier allows 1 cron job)
  3. Click "Create Cronjob"
  4. Fill in these fields:
    Title: Dashboard Uptime URL to call: https://can-logger-dnmjx9hbq-abhishek-e.vercel.app Schedule: Every 5 minutes Timezone: Your timezone
  5. Save — Done! Dashboard now pings itself every 5 min, stays warm 24/7.
Pro tip: Use the exact URL above or just can-logger-dnmjx9hbq-abhishek-e.vercel.app. The cron service does a simple GET request.

Alternative free cron services:

  • UptimeRobot (50 monitors, 5-min checks)
  • Statuscake (free tier)
  • Pingdom (limited free)

Option 2: Vercel Pro (~$20/mo)

Upgrade your Vercel team to Pro for guaranteed always-on functions with zero cold starts.

  1. Upgrade:
    vercel upgrade
  2. Select Pro plan during checkout
  3. Deploy:
    vercel deploy --prod

Benefits:

  • Functions stay warm 24/7
  • Instant response times
  • Production-grade reliability
  • Higher request limits

Option 3: DIY Health Check Endpoint

Add a lightweight health-check endpoint and ping it with cron-job.org (combines Options 1 & 3).

  1. Edit api/index.js and add this at the top of the request handler:
    if (req.url === '/health' && req.method === 'GET') { res.writeHead(200, {'Content-Type': 'application/json'}); res.end(JSON.stringify({status: 'ok', uptime: process.uptime()})); return; }
  2. Deploy:
    vercel deploy --prod
  3. Set up cron on cron-job.org to ping:
    https://can-logger-dnmjx9hbq-abhishek-e.vercel.app/health

Why this works: A dedicated health endpoint returns instantly without loading the full dashboard, so each ping is lightweight.
